Get Navvy running and complete a task in a couple of minutes.

<Steps>

1. **Install the extension.**
   Download the latest build from the [releases page](https://github.com/kemalilketuna/Navvy/releases)
   and load it in Chrome (or grab it from the Chrome Web Store once published).

2. **Open the side panel.**
   Click the Navvy icon, or press `Ctrl/Cmd+E`. You'll see the **Ready** status and the task
   composer.

   ![The Navvy side panel](/shots/sidepanel.png)

3. **Connect a model.**
   Open **Settings → Providers**, choose a provider, paste your API key, pick a model, and press
   **Test connection**. To try Navvy with no setup, leave it on **Navvy Demo (testing)**.

4. **Run a task.**
   Type a plain-language instruction into the composer and press Enter — for example:
   _"Search Wikipedia for the Eiffel Tower and open the article."_ Watch Navvy read the page and
   carry out each step.

5. **Stop any time.**
   Press `Esc` to cancel a running task. Turn on [voice mode](/docs/features/voice) to speak tasks
   instead of typing them.

</Steps>
